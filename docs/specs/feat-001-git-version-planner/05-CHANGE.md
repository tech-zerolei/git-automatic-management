| 0.x 稳定版本 | `conventional-zero` | 非预发布 0.x：fix → patch、feat → minor、breaking → minor；多信号取最高级，高位递增低位归零 |
| 预发布 | `review-prerelease` | 预发布标签、预发布目标和稳定 / 预发布转换一律 needs_review；不自动递增预发布号或转稳定版 |
