# CHG-002：一键本地只读版

确认日期：2026-10-26，Asia/Shanghai。用户在明确说明范围后回复“可以”，授权交付双击启动的本地只读独立工具。

## 本版范围

- 选择一个本地 Git 工作树、手动刷新状态、选择并确认可达稳定标签或输入首次版本。
- 沿用 0.8-draft 的 SemVer、Conventional Commits、0.x、未知/merge/revert、预发布/重复标签复核规则。
- 本地非模型界面显示提交证据与说明；人工确认/版本调整保留理由与冲突，状态变化使确认失效。
- Markdown/JSON 预览及显式导出，拒绝工作树/Git目录、符号链接和未经单独确认的覆盖。
- Linux 本机浏览器窗口、Python 服务仅监听 127.0.0.1；无外部资源、遥测或模型投影。不保存仓库缓存/设置。

## 明确调整

本版不是 Codex 插件；Codex 生命周期、GitHub PAT/SSH 与凭据库不属于本次交付。原 0.8-draft 文档、Q-004 及完整产品验收历史保留，不改为“全部通过”。不执行 commit/tag/fetch/push/发布，不安装钩子或持续仓库监控。

本机无 Tk，采用浏览器加系统文件选择器。依赖使用本机已有 Python/Git/Zenity/浏览器，必要纯前端/版本解析库随包提供。支持普通文件式 Git 仓库及 linked worktree；不明确安全的布局安全拒绝。

技术保护上限（本版实现参数，不是原 NFR 性能承诺）：单操作 30 秒，元数据/单次输出 16 MiB，5000 提交/标签；超过即拒绝或标不完整，不能给出确定版本。无用户请求30分钟退出；窗口内提供显式退出，不轮询仓库。界面通过随机会话认证与严格本机 Origin/Host 校验访问。

## 审查后的实现细节（2026-10-26）

未改变已批准业务范围。按本地只读边界补充：使用本机已有 Bubblewrap 隔离状态读取，并在密封内存文件中固定已验证配置，拒绝 clean/process 外部过滤器；隔离不可用时拒绝。
导出使用 Linux 无名临时 inode（O_TMPFILE）与不覆盖发布，检查目标目录是否移动，发现变化撤销本次发布；不支持该能力的目标文件系统明确报错。此类检查不是对任意同用户恶意进程的全时段文件系统原子保证，不能控制其他进程在操作结束后移动已导出的报告。报告/目录应由用户稳定保管。
预览和导出必须匹配前端当前计划指纹，选择文件后重新检查；Markdown 明确列出 breaking 标记、完整多行提交正文与提交引用。
