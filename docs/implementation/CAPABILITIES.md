## 隔离与证据边界

当前脚本只是 TASK-002 实验，不是可用于任意仓库的可信适配器：没有提供生产操作入口、任意扫描、安装包、钩子或后台服务。网络 syscall 实验仅覆盖 P08 的一次 status 进程树；内容/mtime/ctime 快照不包括 atime，也不能代替所有系统调用的完整审计。加强后的 P07 追踪缺对象读取的 execve，并以仍禁协议联网的弱化 lazy-fetch 参数进行反向对照；对照中的临时 fetch 尝试不能表述为生产路径允许 fetch。

复验脚本采用 Linux /proc、flock 与分层登记的进程组清理，覆盖监督器内部创建的独立组，适用于不主动绕开登记的受控夹具，非任意代码沙箱。必需 strace 检查跳过或探针集合不完整将标记 INCOMPLETE；本机已记录正常批次均无跳过。

宿主 schema 与帮助命令在临时 HOME/CODEX_HOME 下执行，不读取用户认证配置；未启动模型会话或安装插件。公开文档查询在前轮未取得可用网页正文，直接官方页面读取返回 HTTP 403；不以搜索尝试作为能力证据，不据此作平台可用性结论。
